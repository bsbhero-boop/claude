# 모래의 궁전 (Palace of Sands)

1989년 도스 고전 게임 감성의 **도트 횡스크롤 검술 액션**입니다.
지하 감옥에서 시작해 60분 안에 재상 말리크를 쓰러뜨리고 탑의 공주를 구하세요.

빌드 도구나 의존성이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 걷기 · 달리기 (반대 방향을 누르면 돌아서기) |
| `↑` | 점프 · 턱 잡고 매달리기 · 기어오르기 · (칼싸움 중) 막기 |
| `↑` + `→` | 제자리 멀리뛰기 (약 두 칸) |
| 달리면서 `↑` | 도움닫기 점프 (세 칸 구덩이) |
| `↓` | 웅크리기 · 가장자리를 등지고 매달려 내려가기 · 매달린 상태에서 손 놓기 |
| `Shift` (또는 `Z` `X` `Space`) | 줍기 · 마시기 · 베기, 방향키와 함께 누르면 살금살금 걷기 |
| `Esc` / `P` | 일시정지 |

터치 기기에서는 화면 아래에 방향 패드와 `점프` · `행동` 버튼이 나타납니다.

## 원작에서 가져온 규칙

- 한 층(63px) 아래로 떨어지면 무사, 두 층은 체력 1 감소, 세 층 이상은 사망
- 매달렸다가 손을 놓으면 낙하 높이가 줄어든다
- 무너지는 바닥, 가시 함정(살금살금 걸으면 안전), 칼날 함정, 발판으로 여는 철창(시간 제한 있음)
- 회복 물약(빨강)과 최대 체력을 늘리는 생명 물약(초록)
- 막기(↑) 직후 베기로 반격, 경비병은 단계별로 막기 확률 · 반응 속도가 다르다

## 구조

```
index.html        화면 · 오버레이 · 터치 패드 · 스타일
js/core.js        상수, 키보드/터치 입력, WebAudio 효과음 (히자즈 음계)
js/levels.js      레벨 지도(글자 한 칸 = 타일 한 칸)와 경비병 기량 표
js/art.js         팔레트, 레벨 배경 미리 그리기, 움직이는 타일, 횃불 디더링 조명, HUD
js/figure.js      관절 인형 자세 · 애니메이션 키프레임과 도트 렌더러
js/world.js       타일 상태, 함정 · 철창 · 무너지는 바닥 · 파편 갱신, 충돌
js/actors.js      캐릭터 공통 물리(낙하, 착지, 모서리 잡기)와 왕자 상태 기계
js/guard.js       경비병 AI, 칼싸움 판정, 공주
js/main.js        게임 루프, 카메라, 화면 전환, 저장(localStorage)
```

## 레벨 추가하기

`js/levels.js`의 `LEVELS` 배열에 항목을 추가합니다. 각 줄은 같은 길이여야 하고,
세 줄이 한 화면 높이입니다. 글자 뜻은 파일 맨 위 주석에 정리되어 있습니다.
경비병(`g` `k` `V`)은 지도에 나오는 순서대로 `guards` 배열의 설정을 받습니다.
