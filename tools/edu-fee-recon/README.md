# 2026 노인맞춤돌봄 2차 교육비 · 입금 대사 도구

광역지원기관이 제출한 **납부확인서**, 중앙의 **납부 안내자료**, 국민은행 **가상계좌 입금내역**을
브라우저 안에서 자동 대조하여 입금액이 안내·제출 내용과 다른 기관을 찾아내는 오프라인 HTML 웹앱입니다.

- **서버 전송 없음** — 모든 파싱·계산은 브라우저 메모리에서만 수행 (엑셀 파싱: SheetJS 내장)
- **오프라인 동작** — `dist/2026_2차교육비_입금대사도구_v○.○.html` 파일 하나만 있으면 인터넷 없이 실행
  (파일명의 버전이 앱 하단 표기와 일치 — 항상 최신 버전 파일을 사용)
- 이전 ‘직무교육 이수율 통계 대시보드’와 같은 단일 HTML 방식

## 사용법

1. `dist/` 안의 `2026_2차교육비_입금대사도구_v○.○.html`을 브라우저(Chrome/Edge)로 연다.
2. 파일을 한꺼번에 끌어다 놓는다.
   - **납부 안내자료** (전국, 필수) — ‘2차 교육비 납부 안내 및 확인서’ 서식
   - **입금내역** (필수) — 가상계좌 입금 리스트(입금일시·가상계좌번호·입금의뢰인·총입금금액)
     - 안내자료 파일 안에 `입금내역` 시트가 함께 있으면 그 파일 하나로 충분
   - **광역 제출 확인서** (선택, 여러 개) — 시도별 제출본. 조정된 종사자 수·납부금액·비고를 반영
3. 시트별 자동 분류(기준/제출본/입금내역)를 확인하고 **분석 실행**.
4. 결과 확인 후 **결과 엑셀 내려받기** (시도별 요약 / 기관별 결과 / 확인필요·미납 / 잉여·미확인 입금).

## 판정 로직

매칭 키는 **가상계좌번호**(숫자만 비교), 제출 확인서는 **기관코드 → 가상계좌** 순으로 연결.

기대 수납액 = `2차 단가 × 하반기 인원(제출 확인서 기준)` + `1차 잔여분(1차 단가 × 상반기 인원 − 실제 1차 납입액)`
(확인서가 없으면 안내자료 값 = 연간 총액 − 1차 납입액과 동일)

| 판정 | 의미 |
|---|---|
| 정상 / 조정납부 | 실입금 = 기대액 (조정납부는 확인서의 인원 조정 반영 후 일치) |
| 대상아님 | 기대액 0원(1차 일괄·선납) + 입금 없음 |
| 미납 | 입금 0원 |
| 확인필요·변동추정 | 차액이 단가 조합(전담 5만/생지 3만의 2차분·연간분)으로 설명 가능 — **인원 변동이 확인서에 미반영**됐을 가능성 |
| 확인필요·초과입금 | 기대액과 일치하는 입금 외 **잉여 입금** 존재(중복·타기관 오입금 의심). 잉여 금액과 미수납액이 일치하는 미납 기관을 후보로 제시 |
| 확인필요·불일치 | 어느 경우로도 설명 안 되는 차액 |

부가 플래그: `인원조정 a+b→a′+b′`(파란 강조), `조정사유 미기재`, `제출액≠입금액`, `납부일 상이`,
`분할입금 n건`, `확인서 미기재`, `안내액≠산식`, `인원증가분 가능성`, `오입금 후보 있음` 등.

인원조정 기관은 필터 행의 **인원조정** 칩으로 모아 볼 수 있습니다. 조정되었는데 사유가 비어
있으면 `조정사유 미기재` 경고가 붙습니다.

**추정 근거·제출 비고는 마우스를 올리지 않아도 항상 보입니다** — 기관별 표의 특이사항 열에
색으로 구분된 블록으로 바로 표시됩니다: 노란 블록(`추정 근거`)은 이 도구가 차액을 단가로
역산한 계산 결과이고, 파란 블록(`확인서 비고` / `안내자료 비고`)은 광역이나 안내자료에 이미
적혀 있던 원문입니다. 한 기관에 두 가지가 동시에 붙을 수도 있으며(예: 1차 미납으로 일괄
납부 요청이 있었고 차액도 단가로 설명되는 경우) 색으로 구분되어 헷갈리지 않습니다.

## 화면 구성

- **1. 파일 올리기**는 분석을 실행하면 자동으로 한 줄로 접혀(`파일 변경` 버튼으로 다시 펼침)
  KPI·결과가 스크롤 없이 바로 보입니다.
- KPI 카드 바로 아래는 **탭**입니다 — 기본은 실무에서 가장 많이 보는 **기관별 대사 결과**이고,
  **시도별 현황** · **잉여·미확인 입금** · **미연결 확인서**는 탭을 눌러야 나타나므로 큰
  시도별 표가 캡처 화면 바로 아래를 차지하며 화면을 밀어내지 않습니다. 데이터가 없는 탭
  (예: 미연결 확인서가 0건)은 자동으로 숨겨집니다.
- 파일을 불러오거나 분석을 실행하는 동안에는 화면 중앙에 로딩 표시가 뜹니다 — 특히 여러 개의
  광역 제출 확인서를 한 번에 올릴 때, 처리 중이라는 것을 알 수 있도록 파일별 진행 상황을
  표시하고, 필터·정렬 조작은 표만 다시 그리도록 최소화하여 계산량이 많아도 버벅임 없이
  응답합니다.

## 개발

- `index.html` — 앱 소스 (같은 폴더의 `xlsx.full.min.js`를 참조하므로 폴더째로도 오프라인 실행 가능)
- `build.py` — 라이브러리를 인라인하여 단일 배포 파일 생성: `python3 build.py` → `dist/2026_2차교육비_입금대사도구_v{버전}.html`
  (버전은 `index.html`의 `APP_VERSION`에서 자동으로 읽어 파일명에 반영, 이전 버전 산출물은 정리)
- `xlsx.full.min.js` — SheetJS CE 0.18.5 (Apache-2.0)
