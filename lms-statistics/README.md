# 배움터 직무교육 통계 대시보드 — ver9

노인맞춤돌봄서비스 종사자 직무교육 이수 현황을 집계하는 **브라우저 단독 실행 도구**입니다.
배움터 LMS에서 내려받은 엑셀 2종을 올리면 이수율·미이수자·미응시자 등을 자동으로 집계합니다.

| 항목 | 내용 |
|---|---|
| 산출물 | `lms-statistics-v9.html` (단일 파일, 약 1.27MB) |
| 실행 | 파일 더블클릭 (설치·서버·인터넷 불필요) |
| 권장 브라우저 | Chrome / Edge |
| 입력 | `.xlsx` · `.xls` · `.csv` |
| 개인정보 | **전량 브라우저 로컬 처리 · 외부 전송 없음** |

---

## 쓰는 순서

1. **① 회원정보** 엑셀을 올립니다. 한 번 올리면 브라우저에 저장되어 다음부터는 갱신할 때만 올리면 됩니다.
2. **② 수강생목록**(온라인통합수강생목록)을 올립니다. 여러 개를 한꺼번에 올려도 되고, 올릴 때마다 누적됩니다.
3. **데이터 점검** 탭을 먼저 확인합니다. 값이 제대로 읽혔는지 알려 줍니다.
4. 각 탭에서 통계를 확인하고, 화면에 적용한 필터 그대로 **엑셀 다운로드**합니다.

> ⚠️ **수강생목록은 저장되지 않습니다.** 브라우저를 닫으면 다시 올려야 합니다
> (회원정보·설정·검토결정은 유지됩니다).

## 화면

| 탭 | 하는 일 |
|---|---|
| **요약** | 핵심 지표 5종, 예외 인원 안내, 이수율 현황표(배정·채용 대비), 차수별 이수 추이 |
| **데이터 점검** | 원데이터가 제대로 읽혔는지 진단. 인식 안 된 값·형식 이상·회원정보에 없는 ID 명단 |
| **데이터 현황** | 연도·차수별 수강 건수, 과정별 최신 차수, 업로드 파일 목록 |
| **이수율 현황** | 시도 → 시군구 → 기관 3단계 트리, 직군·경력별 이수율 |
| **이수자·미이수자 명단** | 필터·검색 + 미이수 사유·권장 과목 포함. 기관별 시트 분리 다운로드 |
| **미응시·재응시** | 진도 100%·점수 0인 건. 이수자는 자동 제외 |
| **보류·직군변경** | 전직 가능성이 있는 건을 담당자가 승인/반려 |
| **중복자 확인** | 같은 ID가 같은 과정을 2회 이상 수료한 건 |
| **과목별 현황** | 과정별 신청자·수료자·수료율 (원과정/재응시 구분) |
| **개인 조회** | ID·성명 검색 → 판정 근거와 전체 수강 이력, 진단 JSON |
| **설정·도움말** | 이수 기준·차시표·대상 시도 편집, 설정 주고받기, 집계 스냅샷 |

## 이수 판정 규칙

| 경력 구분 | 이수 조건 |
|---|---|
| **신규자** | 해당 직군의 필수과정 수료 |
| **경력자** | 필수과정 수료 **AND** 선택과목 차시 합계 ≥ 기준차시 |

기본 기준차시: 생활지원사 **13차시** · 전담사회복지사 **10차시** (설정에서 변경 가능)

**집계 대상(모수)** = 회원정보에서 `교육대상여부 = Y` · `상태 = 정상` · 시도가 대상 16개 이내 ·
직군이 생활지원사/전담사회복지사(광역 포함) · 교육구분이 신규자/경력자인 사람.

자세한 계산 규칙은 [`lms-statistics-v9.기능사양서.md`](./lms-statistics-v9.기능사양서.md)를 보세요.

## ver8 → ver9 요약

ver8 코드 검토에서 확인된 결함 21건을 수정하고 기능 12건을 추가했습니다.
**집계 숫자가 달라질 수 있는 항목**은 다음과 같습니다.

| | 무엇이 달라지나 |
|---|---|
| **차수** | ver8은 CSV로 올리면 2~12차가 전부 “1차”로 읽혔습니다. ver9는 원본 그대로 읽습니다. |
| **이수일자** | 날짜 셀이 `3/10/26` 같은 형식으로 변형되던 문제를 고쳐, 산출기간(이수일자 기준)이 정상 동작합니다. |
| **대상자 수** | 회원정보를 ID 기준으로 유일화합니다. 중복 행이 있었다면 대상자(분모)가 줄어듭니다. |
| **미응시 건수** | 점수 칸이 **비어 있는** 행은 0점과 구분해 미응시에서 제외합니다(설정에서 되돌릴 수 있음). |
| **이수일자 보유율** | `연도/차수`가 비어 있어도 수료일을 이수일자로 잡습니다. 이전엔 둘 다 비었습니다. |

> 위 항목 때문에 **ver8과 ver9의 숫자가 다를 수 있습니다.** 어느 쪽이 맞는지는
> **데이터 점검** 탭에서 확인할 수 있습니다 — 이상이 하나도 없다면 두 버전의 결과는 같습니다.

전체 변경 내역은 기능사양서 15장을 보세요.

## 개발 (유지보수용)

```bash
cd lms-statistics
node lms-src/build.js      # lms-src/* → lms-statistics-v9.html
node lms-src/test/unit.js  # 계산 엔진 단위 검증 (86건)

npm i -D playwright        # E2E 는 브라우저가 필요합니다
node lms-src/test/e2e.js   # 빌드 결과물 브라우저 검증 (56건)
```

소스 구성은 [`lms-src/README.md`](./lms-src/README.md)를 보세요.

## 유의사항

1. **수강생목록을 모두 올려야 정확합니다.** 일부만 올리면 그만큼 미이수자가 많게 나옵니다.
2. **회원정보에 없는 ID의 수강기록은 전량 제외됩니다.** 몇 건인지는 데이터 점검 탭에 표시되며,
   명단을 내려받아 회원정보 갱신에 쓸 수 있습니다.
3. **경력자의 이수일자는 필수과정 수료일**이며 최종 이수 확정일과 다를 수 있습니다
   (선택과목 수료일이 원데이터에 없습니다).
4. **보류 미검토 인원은 이수자·미이수자 명단 어디에도 나오지 않습니다.** 요약의 미이수자 수와
   명단 건수가 다른 이유이며, 명단 탭 상단에 안내됩니다.
5. 이수 판정은 원데이터의 `수료여부 = 수료`를 그대로 신뢰합니다. LMS 원본이 잘못된 경우는 보정하지 않습니다.
6. **개인정보가 포함된 명단 엑셀은 저장소에 커밋하지 마세요.**
