# 배움터 직무교육 통계 대시보드 — ver11

노인맞춤돌봄서비스 종사자 직무교육 이수 현황을 집계하는 **브라우저 단독 실행 도구**입니다.
배움터 LMS에서 내려받은 엑셀 2종을 올리면 이수율·미이수자·미응시자 등을 자동으로 집계합니다.

| 항목 | 내용 |
|---|---|
| 산출물 | `lms-statistics-v11.html` (단일 파일, 약 1.30MB) |
| 실행 | 파일 더블클릭 (설치·서버·인터넷 불필요) |
| 권장 브라우저 | Chrome / Edge |
| 입력 | `.xlsx` · `.xls` · `.csv` |
| 개인정보 | **전량 브라우저 로컬 처리 · 외부 전송 없음** |

---

## 쓰는 순서

1. **① 회원정보 — [최신 명단 올리기]** 로 배움터에서 받은 최신 회원명단을 올립니다. 저장되므로 새 명단을 받았을 때만 다시 올리면 됩니다.
   퇴사자를 구분하려면 처음 한 번 **[이전 명단 추가]** 로 과거 명단이나 직접 합친 전체 명단을 올리세요(아래 ver11 요약 참고).
2. **② 수강생목록**(온라인통합수강생목록)을 올립니다. 여러 개를 한꺼번에 올려도 되고, 올릴 때마다 누적됩니다.
3. **데이터 점검** 탭을 먼저 확인합니다. 값이 제대로 읽혔는지 알려 줍니다.
4. 각 탭에서 통계를 확인하고, 화면에 적용한 필터 그대로 **엑셀 다운로드**합니다.

> ⚠️ **수강생목록은 저장되지 않습니다.** 브라우저를 닫으면 다시 올려야 합니다
> (회원정보·설정·검토결정은 유지됩니다).

## 화면

| 탭 | 하는 일 |
|---|---|
| **요약** | **집계 대상 선택(현원 / 현원 + 퇴사자)**, 핵심 지표, 예외 인원 안내, 이수율 현황표(배정·채용 대비, **산출기간 차수 선택**), 차수별 이수현황표(원하는 차수 지정), 차수별 이수 추이 |
| **데이터 점검** | **회원 명단 구성(최신 명단·퇴사자) · 대상자 산출 내역**, 원데이터가 제대로 읽혔는지 진단. 인식 안 된 값·형식 이상·회원정보에 없는 ID 명단 |
| **데이터 현황** | 연도·차수별 수강 건수, 과정별 최신 차수, 업로드 파일 목록 |
| **이수율 현황** | 시도 → 시군구 → 기관 3단계 트리, 직군·경력별 이수율 |
| **이수자·미이수자 명단** | 필터·검색 + 미이수 사유·권장 과목 포함, **재직구분(재직/퇴사)**. 기관별 시트 분리 다운로드 |
| **미응시·재응시** | 진도 100%·점수 0인 건. 이수자는 자동 제외 |
| **보류·직군변경** | 전직 가능성이 있는 건을 담당자가 승인/반려 |
| **중복자 확인** | 같은 ID가 같은 과정을 2회 이상 수료한 건 |
| **과목별 현황** | 과정별 신청자·수료자·수료율 (원과정/재응시 구분) |
| **개인 조회** | ID·성명 검색 → 판정 근거와 전체 수강 이력, 진단 JSON |
| **설정·도움말** | 이수 기준·차시표·대상 시도 편집, 설정 주고받기, 집계 스냅샷 |

## 이수 판정 규칙

| 경력 구분 | 이수 조건 |
|---|---|
| **신규자** | 해당 직군의 필수과정 수료 |
| **경력자** | 필수과정 수료 **AND** 선택과목 차시 합계 ≥ 기준차시 |

기본 기준차시: 생활지원사 **13차시** · 전담사회복지사 **10차시** (설정에서 변경 가능)

**집계 대상(모수)** = 회원정보에서 `교육대상여부 = Y` · `상태 = 정상` · 시도가 대상 16개 이내 ·
직군이 생활지원사/전담사회복지사(광역 포함) · 교육구분이 신규자/경력자인 사람.

자세한 계산 규칙은 [`lms-statistics-v11.기능사양서.md`](./lms-statistics-v11.기능사양서.md)를 보세요.

## ver10 → ver11 요약

### 1) 퇴사자 구분 — 명단 합치기를 도구가 대신합니다

배움터 회원명단은 받은 시점의 재직자만 담겨 퇴사자가 빠집니다. 지금까지는 과거 명단과 최신 명단을
엑셀로 합쳐 올려야 했고, 그러면 퇴사자가 대상자(분모)에 섞이고 누가 퇴사자인지 구분할 수 없었습니다.

| 할 일 | 방법 |
|---|---|
| **처음 한 번** | ① [최신 명단 올리기]로 최신 명단 → [이전 명단 추가]로 **지금까지 쓰던 합친 전체 명단**(또는 과거 명단들) |
| **그다음부터** | 새 명단을 받을 때마다 **최신 명단만** 올리면 됩니다. 직전 명단에서 빠진 사람이 **자동으로 퇴사자에 추가**되고, 다시 나타난 사람은 재직으로 되돌아갑니다 |
| 이미 ver10에서 합친 명단을 올려 둔 경우 | 최신 명단만 올리면, 저장돼 있던 합친 명단에서 최신 명단에 없는 사람이 자동으로 퇴사자로 분류됩니다 |

- **현원** = 최신 명단에 있는 사람(판정에는 항상 최신 명단 정보 사용), **퇴사자** = 이전 명단에만 있는 사람.
  도구는 과거 명단 전체가 아니라 **퇴사자 행만** 브라우저에 보관합니다.
- **명단 기준일**은 파일명의 날짜(예: `회원명단_20261012.xlsx`)를 우선 쓰고, 없으면 파일 수정일을 씁니다.
  같은 날 명단은 교체만 하고, 더 이전 날짜 명단을 최신 명단으로 올리면 확인 창으로 묻습니다.
- 요약 탭 위에서 **집계 대상**을 고릅니다: **현원**(기본, 시스템의 현재 교육대상과 같은 기준) / **현원 + 퇴사자**.
  퇴사자 수와 그중 이수자 수는 어느 쪽이든 따로 보여 줍니다.
- 데이터 점검 탭의 **대상자 산출 내역**은 명단 인원이 교육대상여부·상태·시도·직군 조건에서 몇 명씩 빠지는지
  보여 줍니다. 시스템의 교육대상 실인원과 숫자가 다를 때 어느 단계에서 차이가 나는지 확인할 수 있습니다.

### 2) 이수율 현황표 — 산출기간(차수 기준)에서 차수 선택

차수 기준을 고르면 차수별 이수현황표와 같은 **차수 선택기**가 나타납니다. `7-9, 15-21`처럼 띄엄띄엄 지정하거나
번호 버튼으로 고를 수 있고, **신규자·경력자 차수를 따로 지정**할 수도 있습니다(신규자 열은 신규자 차수,
경력자 열은 경력자 차수로 집계). ver10에서 저장한 "시작~끝 차수"는 같은 범위로 자동으로 옮겨집니다.

> 퇴사자를 구분하면(이전 명단을 올리면) 대상자·이수율이 **현원 기준**으로 바뀌어 ver10의 숫자와 달라집니다.
> ver10과 같은 숫자를 보려면 집계 대상을 "현원 + 퇴사자"로 고르세요.

## ver9 → ver10 요약

**요약 탭에 "차수별 이수현황표"를 추가했습니다.** 원하는 차수를 지정하면 그 차수의 이수자를
신규자·경력자 × 직군(생활지원사·전담사회복지사)별로 보여 주고, 같은 모양으로 엑셀에 내려받습니다.

| 차수 | 신규자 생활지원사 | 신규자 전담사회복지사 | 경력자 생활지원사 | 경력자 전담사회복지사 | 합계 |
|---|---:|---:|---:|---:|---:|
| 7차 | … | … | … | … | … |
| … | | | | | |
| 합계 | … | … | … | … | … |

- **차수 지정**: 칸에 `7-9, 15-21`처럼 입력하거나(`15~` = 15차부터 최신까지) 아래 번호 버튼을 눌러 넣고 뺍니다.
  띄엄띄엄 고른 차수도 그대로 표가 됩니다.
- **신규자·경력자 따로 지정**: 신규자는 월 단위, 경력자는 2주 단위로 개강해 **같은 기간이라도 차수 번호가
  다릅니다.** 예를 들어 "신규자 7~9차 + 경력자 15~21차"처럼 각각 지정하면, 지정하지 않은 칸은 `-`로
  비우고 합계에서도 뺍니다.
- **집계 기준**은 이수율 현황표의 산출기간·차수별 추이와 같습니다: 차수 = **필수과정을 수료한 차수**,
  경력자는 선택 차시까지 충족한 **최종 이수자**만 셉니다. 필수만 마치고 선택이 남은 경력자 수는 표 위에 따로 안내합니다.
- 지정한 차수는 브라우저에 저장되어 다음에 열어도 유지되며, 엑셀·인쇄물에 지정 차수가 함께 적힙니다.

> 기존 통계 숫자는 바뀌지 않습니다(새 표를 추가했을 뿐 판정 규칙은 그대로).

## ver8 → ver9 요약

ver8 코드 검토에서 확인된 결함 21건을 수정하고 기능 12건을 추가했습니다.
**집계 숫자가 달라질 수 있는 항목**은 다음과 같습니다.

| | 무엇이 달라지나 |
|---|---|
| **차수** | ver8은 CSV로 올리면 2~12차가 전부 “1차”로 읽혔습니다. ver9는 원본 그대로 읽습니다. |
| **이수일자** | 날짜 셀이 `3/10/26` 같은 형식으로 변형되던 문제를 고쳐, 산출기간(이수일자 기준)이 정상 동작합니다. |
| **대상자 수** | 회원정보를 ID 기준으로 유일화합니다. 중복 행이 있었다면 대상자(분모)가 줄어듭니다. |
| **미응시 건수** | 점수 칸이 **비어 있는** 행은 0점과 구분해 미응시에서 제외합니다(설정에서 되돌릴 수 있음). |
| **이수일자 보유율** | `연도/차수`가 비어 있어도 수료일을 이수일자로 잡습니다. 이전엔 둘 다 비었습니다. |

> 위 항목 때문에 **ver8과 ver9의 숫자가 다를 수 있습니다.** 어느 쪽이 맞는지는
> **데이터 점검** 탭에서 확인할 수 있습니다 — 이상이 하나도 없다면 두 버전의 결과는 같습니다.

전체 변경 내역은 기능사양서 15장을 보세요.

## 유의사항

1. **수강생목록을 모두 올려야 정확합니다.** 일부만 올리면 그만큼 미이수자가 많게 나옵니다.
2. **최신 명단에도 이전 명단에도 없는 ID의 수강기록은 전량 제외됩니다.** 몇 건인지는 데이터 점검 탭에 표시되며,
   명단을 내려받아 회원정보 갱신에 쓸 수 있습니다. 퇴사자의 수강기록은 이전 명단을 올려 두면 제외되지 않습니다.
3. **경력자의 이수일자는 필수과정 수료일**이며 최종 이수 확정일과 다를 수 있습니다
   (선택과목 수료일이 원데이터에 없습니다).
4. **보류 미검토 인원은 이수자·미이수자 명단 어디에도 나오지 않습니다.** 요약의 미이수자 수와
   명단 건수가 다른 이유이며, 명단 탭 상단에 안내됩니다.
5. 이수 판정은 원데이터의 `수료여부 = 수료`를 그대로 신뢰합니다. LMS 원본이 잘못된 경우는 보정하지 않습니다.
6. **개인정보가 포함된 명단 엑셀은 저장소에 커밋하지 마세요.**
