# 잿빛 서울 (Ashen Seoul)

감염 사태로 무너진 서울을 배경으로 한 **도트 횡스크롤 생존 액션**입니다.
지하철 2호선 시청역에서 출발해 한강대교를 건너고, 남산타워 전망대까지 올라가
60분 안에 동생 하나와 함께 마지막 구조 헬기에 타야 합니다.

같은 저장소의 `palace-of-sands/`(모래의 궁전)와 엔진을 공유하는 자매 작품입니다.
빌드 도구나 의존성이 없습니다. `index.html`을 브라우저로 열면 바로 실행됩니다.

## 장 구성

| 장 | 장소 | 새로 나오는 것 |
| --- | --- | --- |
| 1 | 시청역 2호선 (대합실 → 승강장 → 선로) | 쇠파이프, 감염자, 고장난 방화셔터, 끊어진 전선, 비상구 전원 |
| 2 | 한강대교 (상판 → 점검 통로 → 검문소) | 끊긴 상판 도움닫기, 무너지는 아스팔트, 시간 제한 차단 셔터, 교각 아래 혈청 |
| 3 | 남산타워 (아래층 → 전망대) | 턱을 차례로 붙잡고 위층으로, 약탈단 두목 독사, 사랑의 자물쇠, 구조 헬기 |

## 조작

| 키 | 동작 |
| --- | --- |
| `←` `→` | 걷기 · 달리기 (반대 방향을 누르면 돌아서기) |
| `↑` | 점프 · 턱 잡고 매달리기 · 기어오르기 · (싸움 중) 막기 |
| `↑` + `→` | 제자리 멀리뛰기 (약 두 칸) |
| 달리면서 `↑` | 도움닫기 점프 (세 칸 구덩이) |
| `↓` | 웅크리기 · 가장자리를 등지고 매달려 내려가기 · 매달린 상태에서 손 놓기 |
| `Shift` (또는 `Z` `X` `Space`) | 줍기 · 치료 · 쇠파이프 휘두르기, 방향키와 함께 누르면 살금살금 걷기 |
| `Esc` / `P` | 일시정지 |

터치 기기에서는 화면 아래에 방향 패드와 `점프` · `행동` 버튼이 나타납니다.

## 적과 함정

- **감염자**: 느리게 다가와 할퀸다. 막지 못하지만 막기(↑)로 할퀴기를 튕겨낼 수 있다.
- **약탈자**: 야구방망이·마체테를 들고 공격을 막아낸다. 막은 직후 반격이 통한다.
- **독사**: 방독면을 쓴 약탈단 두목. 소방도끼를 휘두르고 막기 확률이 가장 높다.
- **유리 조각·철근**: 달려서 밟으면 죽는다. 살금살금 걸으면 안전.
- **방화셔터**: 주기적으로 내리꽂힌다. 올라간 순간에 지나간다.
- **끊어진 전선**: 물웅덩이에 불꽃이 튀는 동안 밟고 있으면 감전된다.
- 두 층 아래로 떨어지면 체력 1 감소, 세 층 이상은 사망. 한강으로 떨어지면 끝.

## 구조

```
index.html        화면 · 오버레이(재난문자 타이틀) · 터치 패드 · 스타일
js/core.js        상수, 입력, WebAudio 효과음 (사이렌, 감전, 신음, 헬기)
js/levels.js      레벨 지도(글자 한 칸 = 타일 한 칸), 적 설정, 소품 배치
js/art.js         테마별 팔레트와 타일 그림(지하철 타일·점자블록·선로, 다리 아스팔트·철골, 타워 패널), 조명
js/backdrop.js    다리 위 하늘·스카이라인(63빌딩·남산타워) 시차 스크롤, 강, 전망창 밖 서울, 재, 헬기
js/figure.js      관절 인형 자세 · 애니메이션과 도트 렌더러, 인물 외형·무기
js/world.js       타일 상태, 함정 · 셔터 · 무너지는 바닥 · 전선 갱신, 충돌
js/actors.js      캐릭터 공통 물리(낙하, 착지, 모서리 잡기)와 생존자 상태 기계
js/guard.js       약탈자·감염자 AI, 싸움 판정, 동생
js/main.js        게임 루프, 카메라, 화면 전환, 저장(localStorage)
```
